# EWL Development Rules

This system uses the Enterprise Web Library (EWL), a .NET framework for web applications.

## Code Conventions

- All `.cs` and `.csproj` files must use UTF-8 encoding with a BOM (byte order mark).
- All text files must use CRLF (`\r\n`) line endings.
- Use tabs for indentation, not spaces, in C# files.

## Generated Code

Every project in the solution has a `Generated Code` folder. These folders and their contents are fully regenerated by the Development Utility during every build. Never manually edit files in any `Generated Code` folder; your changes will be overwritten.

## File Organization

- `Library` is the core project containing shared logic, configuration, and providers.
- `Website` (or other web-application projects) contain page classes and UI logic built on EWL's web framework.
- `Solution Files` contains solution-level build configuration.

## EWL Patterns

- Page classes use EWL's code-generation-based URL routing. Each page is a class that inherits from a generated base.
- UI is built using EWL's component model with methods that return component collections, not Razor views.
- Data access uses EWL's generated data-access layer based on database schema, producing retrieval and modification classes in `Generated Code`.
- Configuration is defined in XML files validated against XSD schemas in the `Configuration` folders.
